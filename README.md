Repositorio académico para la práctica de control de versiones de Git y GitHub del curso SOFT-09
# SOFT-09_documentacion

## Curso
Introducción a la Ingeniería del Software (SOFT-09) - Universidad CENFOTEC[cite: 1].

## Propósito de la práctica
Aplicar los conceptos fundamentales de control de versiones utilizando Git y GitHub, simulando flujos de trabajo profesionales para la gestión de código y documentación[cite: 2, 3].

## Descripción del contenido
Este repositorio contiene los archivos iniciales de la práctica, incluyendo la licencia MIT y el archivo de código fuente en Java (`HolaMundo.java`) estructurado mediante un historial de commits controlados[cite: 3, 4, 6].
